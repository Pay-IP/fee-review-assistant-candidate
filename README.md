# Interview environment setup

This package contains dependency manifests only. It lets you install the supported default Python 3.12 and React/Vite dependencies before the interview without revealing the exercise.

You may instead use backend and frontend languages or frameworks that better represent your normal work. If you do, prepare that environment yourself and tell the interviewer during planning. Alternative stacks are assessed against equivalent engineering outcomes and receive no penalty.

Python: create and activate a virtual environment, then run `python -m pip install -r backend/requirements-dev.txt`.

Frontend: run `npm install` in `frontend/`.
